## ❓ Frequently Asked Questions

### General Questions

**Q: Is this free to use?**  
A: Yes! MIT licensed. See [README.md - License](README.md#-license)

**Q: Does it work offline?**  
A: After initial CDN load, yes (demo data mode). See [QUICKSTART.md - Demo Data](QUICKSTART.md#-demo-data-notice)

**Q: Can I use real market data?**  
A: Yes! Follow [README.md - API Integration Guide](README.md#-data-sources-production-integration)

**Q: What browsers are supported?**  
A: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+. See [QUICKSTART.md - Browsers](QUICKSTART.md#-method-1-direct-browser-open-easiest)

### Technical Questions

**Q: How do I change update frequency?**  
A: Edit `js/main.js` intervals. See [QUICKSTART.md - Customization](QUICKSTART.md#-customization-quick-tips)

**Q: Can I add more cryptocurrencies?**  
A: Yes! Modify data generators in `js/utils.js` and add buttons in HTML.

**Q: How do I integrate WebSocket?**  
A: Replace intervals in `js/main.js` with WebSocket connections. Example in [README.md](README.md#-data-sources-production-integration)

**Q: Is mobile responsive?**  
A: Yes! Fully responsive with breakpoints at 768px, 1200px, 1440px. See [FEATURES.md - Responsive](FEATURES.md#-responsive-breakpoints)

### Feature Questions

**Q: What does Fear & Greed Index mean?**  
A: Market sentiment indicator (0=fear, 100=greed). See [QUICKSTART.md - Fear & Greed](QUICKSTART.md#-fear--greed-index)

**Q: Are whale transactions real?**  
A: In demo mode, simulated. With API integration, real. See [README.md - Whale Alert API](README.md#-data-sources-production-integration)

**Q: Can I customize colors?**  
A: Yes! Edit CSS variables in `css/style.css`. See [QUICKSTART.md - Customization](QUICKSTART.md#-customization-quick-tips)

**Q: How often does data update?**  
A: Ticker: 3s, Whale: 8-15s, Fear/Greed: 60s. See [FEATURES.md - Update System](FEATURES.md#-real-time-update-system)
